# phone_ai_console
这是一个基于 Python、AI 大模型和 ADB 的安卓手机智能控制系统，旨在通过自然语言指令操控手机，降低手机自动化操作的技术门槛。 项目采用 Python 和 Flask 搭建本地服务，通过 USB 和 ADB 连接安卓手机，利用截图获取手机当前界面，并将截图及任务要求发送给 AI 大模型（目前使用 DeepSeek API）进行视觉识别和操作决策。 系统还设计了操作日志、执行过程截图以及任务控制等功能，支持用户用自然语言完成打开应用、发送消息、填写信息等任务。我对安装流程进行了封装，集成 ADB 工具及必要的 Python 依赖，尽量减少用户的配置工作。 项目的长期目标是将其发展为一个通用 AI 手机助手，让 AI 不仅能够回答问题，还能真正理解手机界面并代替用户完成实际操作。
