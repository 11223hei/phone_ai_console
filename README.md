# AI Android Assistant

**一个基于 Python、DeepSeek API 和 ADB 的 AI 安卓手机自动化助手。**

通过自然语言描述任务，让 AI 理解手机当前界面，并自动执行点击、滑动、文字输入等操作。让 AI 不只是回答问题，还能真正操作手机。

## 项目介绍

本项目是一个运行在 Windows 电脑上的安卓手机智能控制系统。

用户通过本地 Web 界面输入自然语言任务，系统将手机屏幕截图发送给 AI 大模型进行分析。AI 根据当前界面判断需要执行的操作，再由 Python 调用 ADB 控制手机完成相应动作。

整个过程形成一个循环：

**屏幕截图 → AI 视觉识别 → 操作决策 → ADB 执行 → 截图反馈**

项目使用 DeepSeek API 提供 AI 能力，使用 ADB 实现安卓设备控制，并通过 Python 完成任务调度和执行流程管理。

## 主要功能

- **自然语言控制：** 使用日常语言描述任务，无需手动编写自动化脚本。
- **屏幕视觉识别：** AI 根据手机实时截图理解当前界面。
- **自动化操作：** 支持点击、滑动、文字输入等基本操作。
- **连续任务执行：** 根据界面变化持续分析并执行后续操作。
- **过程截图反馈：** 可以查看任务执行过程中的屏幕状态。
- **任务控制：** 支持暂停、停止等执行控制。
- **本地 Web 界面：** 通过电脑浏览器与助手交互。

## 技术架构

| 技术 | 用途 |
|---|---|
| Python | 核心程序与任务调度 |
| Flask | 本地 Web 服务 |
| ADB | 安卓设备连接与控制 |
| DeepSeek API | AI 视觉理解与操作决策 |
| Pillow | 图像处理 |

## 使用方法

### 1. 准备环境

- Windows 10/11 电脑
- 一部安卓手机
- USB 数据线
- 可用的 DeepSeek API Key
- 手机开启开发者选项和 USB 调试功能

### 2. 安装程序

1. 下载项目发布的安装包。
2. 按照安装程序提示完成安装。
3. 确保手机已经开启 USB 调试。
4. 使用 USB 数据线连接手机和电脑。
5. 手机弹出 USB 调试授权提示时，选择允许。

### 3. 配置 API

在程序配置文件 `.env` 中填写自己的 DeepSeek API Key。

请勿将个人 API Key 上传到公开代码仓库。

### 4. 启动程序

运行安装后的启动程序，等待本地服务启动。

随后按照程序提示打开本地 Web 页面，进入 AI 助手操作界面。

### 5. 开始使用

在任务输入框中输入希望 AI 完成的任务，例如：

- 打开微信。
- 给某位联系人发送一条消息。
- 打开浏览器搜索指定内容。
- 在指定页面填写信息。
- 根据屏幕上的题目完成相关操作。

AI 会先理解任务和当前手机界面，再根据识别结果执行操作。

任务执行过程中，可以查看操作截图和执行日志，并根据需要暂停或停止任务。

## 注意事项

1. 首次连接手机时，需要在手机上授权 USB 调试。
2. 使用前请确保电脑能够正常访问 DeepSeek API。
3. API 调用会产生费用，具体费用以 DeepSeek 官方计费规则为准。
4. AI 的视觉识别和操作决策并非始终准确，复杂界面可能出现误操作。
5. 涉及支付、删除、转账等重要操作时，请务必人工确认。
6. 请勿将 API Key、个人隐私或其他敏感信息上传至公开仓库。
